Arquitetura de Visão Computacional

Pipeline de 4 camadas usado por empresas de ponta em Israel e EUA.

Câmera da maquininha / celular / tablet
App (Flutter ou Capacitor + Next.js 15)
Pré-processamento local (MediaPipe / Canvas / TFLite)
1. GPT-4o Vision / Gemini 2.5 / Claude Vision → zero-shot
2. Google Cloud Vision / Azure AI Vision → fallback clássico
3. YOLOv11 customizado → detecção rápida + bounding box
4. Modelo edge TFLite → offline na maquininha
Retorna: SKU + nome + confiança + bounding box + quantidade
Adiciona automaticamente no carrinho / estoque / relatório

Roadmap de modernização

Plano realista em 3 fases (estilo big tech).

1

Fase 1 – Fundação (1-2 meses)

  • Migrar frontend para Next.js 15 + React 19 + TypeScript + Tailwind
  • Criar design system próprio (cores Nox + tipografia moderna)
  • Backend NestJS + PostgreSQL
  • Autenticação moderna (Clerk / Auth.js)
  • Manter e fortalecer o modo offline
2

Fase 2 – Visão Computacional (2-3 meses)

  • Cadastro de produto por foto (GPT-4o / Gemini)
  • Reconhecimento em tempo real no PDV (YOLO + fallback cloud)
  • Exportar modelo para TFLite (roda na maquininha)
3

Fase 3 – Escala e inteligência

  • Multi-câmera + depth (estilo Mashgin)
  • Integração com balança
  • Server-Driven UI (padrão Nubank)
  • HubSpot / Salesforce + Segment
  • A/B testing com LaunchDarkly ou Vercel Edge Config
